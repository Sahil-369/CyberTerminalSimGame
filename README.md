# Cyber Terminal Simulator Game
This is a Game that simulates linux terminal. It is a short game with few missions written purely in python. It is purely made by a human no ai is used. Also this is my first project. I made this just to see my learning progress.

A terminal-based short cyber security adventure game written in Python.

## Features

- Fake file system
- Mission system
- Fake Nmap scanning
- Fake Metasploit console
- Rank progression

## Run

python main.py
